# Security

MetroPulse is a local teaching simulator. It should not receive production
credentials, customer data, or access to production systems.

For a vulnerability that should not be discussed publicly, use the repository's
[private vulnerability reporting](https://github.com/Mason-Ye-Project/metropulse-pipeline-incident-lab/security/advisories/new)
flow. For ordinary bugs or documentation corrections, open a GitHub issue.

The maintainers support the latest `v1.0.x` release line. Published book tags are
kept immutable so readers can reproduce the printed evidence.
